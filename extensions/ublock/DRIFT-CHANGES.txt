uBlock Origin 1.75.0 (Chromium build, https://github.com/gorhill/uBlock/releases/tag/1.75.0),
licensed GPLv3 (see LICENSE.txt), bundled with Drift with five small changes:

1. js/vapi-background-ext.js, normalizeDetails(): Electron reports tabId -1 for every
   webRequest event, so uBO would treat all traffic as "behind-the-scene" and filter
   nothing per-site. When tabId is -1, ask Drift (self.__driftTabFor) which tab the
   request belongs to.

2. js/vapi-background.js, onPortConnect(): Electron doesn't fill port.sender.tab for
   content scripts, so cosmetic filtering and scriptlets had no tab. Ask Drift the same way.

3. js/vapi-background.js, vAPI.adminStorage: Electron's chrome.storage.managed.get()
   returns the contents of storage.local. uBO caches that result into storage.local,
   so storage doubled on every launch (gigabytes within days) and startup slowed to a
   crawl. Drift has no admin policies, so managed storage is treated as absent and the
   stale cachedManagedStorage entry is removed.

4. manifest.json: added a "key" so the extension ID is always kfjbnefaejpefdfmciibdijcalgdfaec, wherever Drift is
   installed (an unpacked extension's ID otherwise depends on its folder path, which reset
   uBO's settings whenever Drift moved).

5. background.html loads js/drift-hints.js (copied from extensions/drift-hints/bg.js by
   scripts/sync-hints.js, with drift-identity.json). It adds Chromium's User-Agent client-hint
   headers that Electron leaves off page loads, and runs here so it doesn't need a process of
   its own. It doesn't touch uBO's filtering.

Nothing else is modified.
